Exam Definitions

HTTP
Hypertext Transfer Protocol used for transferring web documents between browser client and web server.
DNS
Domain Name System that converts hostnames like lahore.comsats.edu.pk into server IP addresses.
Client-Server
Architecture where the user browser requests data and the host server returns the response.
Void Element
Elements that have no closing tag and no text content, such as <br>, <hr>, and <img>.
