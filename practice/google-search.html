GET Request URL Format:

GET /search?q=COMSATS+Lahore HTTP/1.1
Host: www.google.com

POST Request Payload Format:

POST /login HTTP/1.1
Host: cuonline.cuilahore.edu.pk
Content-Type: application/x-www-form-urlencoded

reg_no=FA22-BCS-078&pass=secret123
Lab Note: Passwords must never be submitted using GET because parameters get appended directly to the URL, creating entries in the browser history and server access logs.
